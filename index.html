Sobre mí

D

esarrollador Full Stack, técnico en Desarrollo Web certificado y estudiante de Desarrollo de Software, enfocado en la creación de sistemas y aplicaciones web funcionales orientadas a resolver problemas reales.

Cuento con experiencia en frontend con HTML, CSS y JavaScript; backend con Python y FastAPI, trabajando también con SQL y SQLite. Manejo Git y GitHub para el control de versiones y los flujos de trabajo, conocimientos en deploy de aplicaciones y sistemas web.

A través de mis proyectos trabajé con interfaces web, APIs, bases de datos y lógica de negocio, aplicando lógicas de ingeniería como ciclos de vida del software, metodologías ágiles e ingeniería de requisitos. Construyo aplicaciones desde cero y resuelvo los problemas de los clientes.

Me caracterizo por la atención al detalle, el enfoque en la resolución de problemas y el aprendizaje práctico y constante: me gusta entender cómo funcionan las herramientas que utilizo y convertir lo aprendido en proyectos reales.

Actualmente busco seguir creciendo profesionalmente, tanto formando parte de equipos de desarrollo como realizando proyectos para clientes.

Calculadora · 2026

¿Le ganaste a la inflación?

Calculadora 100% frontend, sin frameworks ni build. Trae al día los datos oficiales del INDEC, aplica una regla de negocio auditable —aumento nominal contra inflación acumulada, con la fórmula documentada— y lo presenta como un ticket térmico: historial en localStorage, export a CSV en formato es-AR y descarga del ticket como imagen.

  • HTML
  • CSS
  • JavaScript
  • Datos INDEC
  • Playwright
  • Vercel

Evidencia: datos oficiales en vivo, lógica de negocio documentada y pruebas automatizadas —102 asserts (unit + E2E) corriendo en CI ante cada cambio.
